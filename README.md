# 👕 Poomo – Clothing Shop Website  

A modern, responsive clothing shop management web application built with **HTML, CSS, Bootstrap, JavaScript, PHP, and MySQL**.  
This project is designed to manage products, customers, and shop operations easily through an interactive web interface.  

---

## ✨ Features  
- 🛍️ Product catalog with categories  
- 👤 Customer registration & login  
- 🔐 Secure user authentication  
- 🛒 Shopping cart & checkout  
- 💳 Payment gateway integration with **PayHere Demo**  
- 📊 Admin dashboard for product & order management  
- 📱 Responsive design (Bootstrap)  

---

## 🛠️ Tech Stack  
**Frontend:** HTML, CSS, Bootstrap, JavaScript  
**Backend:** PHP  
**Database:** MySQL *(HeidiSQL / Workbench for management)*  
**Payment Gateway:** PayHere Demo Integration  
**Hosting:** Local (XAMPP for development), future live hosting planned
